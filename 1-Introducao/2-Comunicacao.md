## 1.2 Comunicação

Como iremos inicialmente usar o Github para hospedar o curso, gostaríamos de pedir que, para qualquer dúvida referente a alguma aula ou melhoria, você crie uma **ISSUE** no nosso repositório. Assim conseguimos resolver e manter uma padronização de perguntas/respostas dentro do projeto.

Se o problema for no próprio e2e (um comando que quebrou, uma documentação que confundiu), o e2e tem um canal direto com o time que o mantém:

```bash
npx e2e feedback --type bug -m "o que aconteceu, em uma ou duas frases"
```

Ele nunca envia o conteúdo do seu app nem suas senhas, mas não cole dados sensíveis na mensagem.
